# References

These references were used to shape the documentation structure and API documentation style.

- Microsoft Learn, "Create web APIs with ASP.NET Core": https://learn.microsoft.com/en-us/aspnet/core/web-api/
- Microsoft .NET, "ASP.NET Web APIs": https://dotnet.microsoft.com/apps/aspnet/apis
- Microsoft .NET, ".NET application architecture guides": https://dotnet.microsoft.com/en-us/learn/dotnet/architecture-guides

Applied documentation principles:

- Keep an onboarding overview separate from detailed references.
- Document runtime configuration and dependency injection clearly.
- Describe API contracts in terms of routes, request DTOs, response DTOs, and status codes.
- Document the data model separately from HTTP endpoints.
- Explain database setup and stored procedure dependencies because they are operational requirements.
- Call out limitations and maintenance risks explicitly.
