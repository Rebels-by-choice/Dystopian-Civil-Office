Welcome to Dystopian Civil Office!

Dystopian Civil Office provides our idea for anarchic world, but with simular functionalities to real civil office in Poland. View, add, update and delete any data you want, enjoy daily statistics and have fun with our system! This is a demo open source app for learning purposes, so feel free to reverse-engineer our code on github repository. Infrastructure documentation is available in our docs folder on main repo page. hAvE fUn!
